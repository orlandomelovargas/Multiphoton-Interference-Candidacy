# Multiphoton-Interference-Candidacy
This repository contains the material associated with the PhD candidacy examination **“Partial Indistinguishability and Sector Structure in Multiphoton Interference: From the Effective Single-Particle Matrix to the Semiclassical Limit.”** The file `PhD_Candidacy_Examination.pdf` contains the main research proposal and presents the physical motivation, theoretical framework, main results obtained so far, and the open problems defining the doctoral research. The companion document `Mathematical_Appendices.pdf` collects the complete mathematical derivations supporting the results presented in the proposal, including the exact probabilistic formulation, spectrum–diagonal geometry, representation-theoretic constructions, multiplicity spaces, projected kernels, physical multiplicity densities, stationary-phase analysis, and the derivation of the sectorial classical map. The Wolfram Language file `Multiphoton_Interference_Calculations.wl` contains the symbolic and numerical implementations used to generate the compatible frames, evaluate Gram matrices and multiplicity-space densities, compute detection probabilities and Hessians, and produce the numerical results and figures presented in the documents. The calculations were developed and tested with Wolfram Mathematica 14.5.


## Repository contents

- `PhD_Candidacy_Examination.pdf` — Main PhD candidacy proposal.
- `Mathematical_Appendices.pdf` — Detailed mathematical derivations and supporting calculations, organized in Appendices A–I.
- `Multiphoton_Interference_Calculations.wl` — Wolfram Language implementation of the analytical and numerical calculations used throughout the proposal and appendices.
